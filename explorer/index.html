SPATIAL

A pixel is not a promise.

Band, mode, processing and viewing angle determine what a resolution number means. A finer output grid does not create finer observations.

TEMPORAL

Repeat ≠ usable revisit.

Orbit repeat, constellation coverage, scan cadence, cloud-free observations and product latency answer different questions.

EVIDENCE

Follow the whole chain.

Platform → sensor → measured property → product → analysis → application. An observation alone does not establish an outcome.
